# Délices ely

Sitio web del restaurante en Las Tablas, Panamá.

Sitio estático: index.html, style.css, app.js y menu-data.js. Las imágenes están en assets/.

Para publicarlo con GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

La disponibilidad se configura en menu-data.js con consultar, disponible o agotado.
